# Weather App

## Description
A simple and user-friendly weather application that displays weather information, including temperature, humidity, wind speed, and weather conditions for different locations.

## Features
- Search weather by city name
- Display current temperature
- Show humidity and wind speed
- Display weather conditions
- Simple and attractive user interface
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Weather API (if used)

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name to check the weather.

## Purpose
To provide users with quick and easy access to weather information.
